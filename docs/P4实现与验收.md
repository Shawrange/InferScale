# P4 实现与验收

更新：2026-09-23。实验工具已实现，真实 GPU 对比尚未运行。P3 GPU 取消沿用用户人工确认。

## 已交付

- 三类可复现轨迹：Mixed、Shared Prefix、Hot Prefix；统一 seed 与计划到达时间。
- open-loop 固定计划到达，客户端容量不足显式 not_sent；closed-loop 仅用于冒烟。
- 有界预检、warmup、测量与 drain；样本逐条落盘，中断标 incomplete。
- 客户端 UUID 与 Gateway request/attempt 日志关联；重试只算一个逻辑请求，未知 attempt 数保留 null。
- TTFT/E2E P50/P95、终态分母、窗口吞吐、drain 完成、SLO goodput、Worker 分布与可信 usage 指标。
- 后端三组缓存指标快照；不同环境/轨迹/参数隔离比较，三轮结果保留均值、范围和逐轮分母。
- 原生服务器四策略配置与随机化 36 轮计划，Markdown/JSON/CSV 汇总及源码部署包。

## 验证

当前全套 157 项 CPU 测试通过，包括原有网关回归、B1–B6、两次 attempt 对应一次成功、drain 取消、提交后截断、策略配置不一致拒绝运行，以及生成样本到复算报告的 socket 命令链。

部署包的 99 个文件 SHA-256 已逐一核对；解压到独立目录、强制从包内 src 导入后，157 项测试再次通过（71.57 秒）。包内 plan/generate 命令、Ruff lint/格式和离线锁文件检查通过。

这些测试验证实现与统计口径，不代表双 4090 性能。fake 模式结果自动标记 synthetic，不纳入正式收益比较。P2 历史长跑和 P3 服务器验收保持原版本归属。
