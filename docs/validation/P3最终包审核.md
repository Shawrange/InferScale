## 修复验证流程

本地 `scripts/server_smoke.py` 已增加 `/health/live` 策略记录及 `--expect-policy` 参数。指定期望策略后，若不匹配立即失败，不发生成请求；报告记录 actual/expected policy。匹配的 12 项 socket smoke 与不匹配时零后端调用两个定向测试通过（2.78 秒），Ruff 通过。

原生进程部署的复验命令见 [P3复验](../../deploy/P3复验.md)。保留服务器的 127.0.0.1 Worker 地址，不直接使用会生成 Docker 服务名的配置生成器。每轮使用独立配置/报告，停止旧 Gateway 后再启动新实例，并核对 `/health/live` 与 routing_decision。

下一步只需补：正确策略的三轮功能 smoke；一次有前后指标及关联后端终止证据的取消。正式性能对比仍属于 P4。
